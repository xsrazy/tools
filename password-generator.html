What makes a password strong

Strength is entropy: length times the size of the character pool, measured in bits. A 16-character password from all four sets carries about 100 bits, which is far beyond brute force. Length matters more than exotic symbols: every extra character multiplies the search space.

The generator uses crypto.getRandomValues, the browser's cryptographic random source, the same one password managers rely on.

Password habits that actually work

  • Unique per site: reuse is how strong passwords get defeated.
  • Use a password manager so you only memorize one master password.
  • 16+ characters for email, banking and anything tied to money.
  • Turn on two-factor authentication wherever it is offered.

Password generator FAQs

Are the generated passwords truly random?
Yes. Passwords are generated with the browser's cryptographic random number generator (crypto.getRandomValues), the same source password managers use. They are never sent to any server.
How long should my password be?
At least 16 characters for important accounts. Length beats complexity: a 20-character password of mixed characters has far more combinations than any 8-character one, however exotic.
What does the strength meter measure?
It measures entropy in bits: password length times the logarithm of the character pool size. Above 60 bits is strong; above 90 bits is very strong against brute force.
Should I reuse a generated password?
No. Generate a unique password per site and store them in a password manager. Reuse is the most common way strong passwords get defeated.
