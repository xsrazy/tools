# Micro Tools Hub

**Live: https://tools.xsrazy.web.id**

Micro Tools Hub is a collection of 1,108 free online tools that run in the browser. No sign-up, no fees. Visitors open a tool, use it instantly, and leave; almost everything is computed locally on the visitor's own device.

## Site Contents

Tools are grouped into 9 categories:

| Category | Tools |
|---|---|
| Developer | 377 |
| Converters | 170 |
| Calculators | 155 |
| Image | 141 |
| Text | 76 |
| Generators | 68 |
| Business | 63 |
| Everyday | 47 |
| Downloaders | 11 |

Examples: word counter, password generator, meme generator, JSON formatter, currency converter with live rates, mortgage calculator, image compressor, HEIC to JPG converter, QR code generator, invoice maker, and a set of media downloaders. The homepage lists every category with a search box, and each tool has its own page with a short guide and FAQ.

## Frontend

- Plain static HTML, CSS, and vanilla JavaScript. There is no framework and no build output beyond the generated pages themselves.
- Pages are generated by `scripts/generate.js` from `data/tools-registry.json` (the single registry of all 1,108 tools) using `scripts/templates/page.html`. 1,057 pages are generated this way; 51 pages (mostly calculators and interactive tools) are handbuilt HTML files kept in the repo.
- Generated pages include FAQ sections with JSON-LD structured data. `sitemap.xml` lists 1,113 URLs.
- The generator also syncs the shared footer, the stylesheet version, and the sitemap every time it runs.

## Backend

There is almost no backend. Only two Vercel serverless functions exist:

- `api/rates.js` proxies the Frankfurter API to provide live currency exchange rates, cached at the edge for 6 hours.
- `api/dl.js` resolves downloadable media for the Downloader tools.

Everything else runs fully client-side in the visitor's browser.

## Repository Notes

- Edit `data/tools-registry.json`, then run `node scripts/generate.js` (this is also the Vercel build command) and push. Vercel builds and deploys from this repo's `main` branch.
- `.vercelignore` only excludes `hidden_files/` and `*.md`. The `sitemap.xml` file must stay in the repo because the generator reads and updates it.
- The Vercel project output directory is set to the repository root.
