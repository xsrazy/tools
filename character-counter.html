How the counts work

Characters are Unicode code points: every letter, space, punctuation mark, line break and emoji counts as exactly one. Words are runs of non-whitespace characters. Sentences end on ., !, ? or …. Paragraphs are non-empty lines. UTF-8 bytes is the storage size of your text, which matters for databases and APIs. Reading time assumes 200 words per minute.

Know the limits before you post

  • X (Twitter): 280 characters per post.
  • Instagram: 2,200 characters per caption, but only the first ~125 show before the "more" link.
  • SMS: 160 characters per segment; longer texts split and bill per segment.
  • Facebook: 63,206 characters per post, effectively unlimited.

Bars turn amber at 80% of a limit and red when you go over.

Character counter FAQs

How does the character counter count characters?
It counts Unicode code points, so every letter, space, punctuation mark, line break and emoji counts as exactly one character. Emoji count as one here, even though some systems store them as two code units behind the scenes.
What is the character limit on X (Twitter)?
A standard post on X is limited to 280 characters. That is the number the meter above tracks, and it is the limit most people write against.
What is the Instagram caption character limit?
Instagram captions can be up to 2,200 characters long. Only the first 125 or so show in the feed before the "more" link, so put the hook first and use the meter to check the hard limit.
How many characters fit in one SMS?
One SMS segment holds 160 characters with the standard GSM alphabet. Messages longer than that are split into 153-character segments and billed per segment, so staying under 160 keeps it to a single text.
Is my text uploaded anywhere?
No. All counting happens in your browser with JavaScript. Your text never leaves your device.
